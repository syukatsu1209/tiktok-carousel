プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-10-12

1. 本ツールについて / About

Carousel Drafter（以下「本ツール」）は、運営者が自分のTikTokアカウントに写真カルーセルの下書きを送るための個人用ツールです。運営者以外の利用者を想定していません。
Carousel Drafter is a single-user tool that sends photo-carousel drafts to the operator's own TikTok account. It is not offered to other users.

2. 取得する情報 / Data we access

  • TikTokのOAuthで発行されるアクセストークン・リフレッシュトークン・Open ID（スコープ：user.info.basic, video.upload）
    TikTok OAuth access token, refresh token and Open ID (scopes: user.info.basic, video.upload)
  • 本ツールは、他のユーザーの個人情報、動画、コメント、フォロワー情報を取得しません。
    The tool does not access other users' personal data, videos, comments or followers.

3. 利用目的 / How data is used

トークンは、運営者が作成した画像をTikTokの受信箱（下書き）に送るためだけに使用します。公開は運営者がTikTokアプリで手動で行います。
Tokens are used only to upload images created by the operator to the operator's TikTok inbox as drafts. Publishing is done manually by the operator in the TikTok app.

4. 保管 / Storage

トークンは暗号化したうえで運営者のGitHubリポジトリに保存し、復号鍵はGitHub Secretsで管理します。第三者への販売・共有は行いません。
Tokens are stored encrypted in the operator's GitHub repository; the decryption key is kept in GitHub Secrets. Data is never sold or shared with third parties.

5. 削除 / Deletion

TikTokアプリの設定から本ツールへのアクセスを取り消すことで、いつでも連携を解除できます。運営者はリポジトリ内の暗号化トークンを削除します。
Access can be revoked at any time from TikTok's app settings; the operator then deletes the stored encrypted token.

6. お問い合わせ / Contact

本ツールのGitHubリポジトリのIssueからご連絡ください。
Please contact us via the Issues page of this tool's GitHub repository.
